# 附录 A：同刻收盘与延迟一根 bar 两种评估口径

模型均使用相同的滚动窗口。神经网络数字为每窗口五个独立 seed 先分别评分、再取均值；
Ridge 与 LightGBM 为固定模型。表中 RankIC、ICIR 和十分组多空均先在窗口内计算，再对八个
测试窗口等权平均。

| 模型 | 口径 | RankIC | ICIR | 十分组多空/期 |
|---|---|---:|---:|---:|
| Ridge | 同刻收盘 | 0.0912 | 0.4921 | 7.40 bp |
| Ridge | 延迟一根 bar | 0.0297 | 0.1598 | −0.89 bp |
| LightGBM | 同刻收盘 | 0.1016 | 0.5503 | 10.76 bp |
| LightGBM | 延迟一根 bar | 0.0397 | 0.2129 | 0.82 bp |
| MLP | 同刻收盘 | 0.0974 | 0.5025 | 9.81 bp |
| MLP | 延迟一根 bar | 0.0384 | 0.1977 | 0.99 bp |
| GRU | 同刻收盘 | 0.1055 | 0.5328 | 10.99 bp |
| GRU | 延迟一根 bar | 0.0463 | 0.2341 | 1.05 bp |

精确值、各窗口最小值和最大值见
[`tables/appendix_a_execution_protocols.csv`](tables/appendix_a_execution_protocols.csv)。

同刻收盘口径把产生信号的 bar 收盘价同时当作可成交价格，四模型 RankIC 都在 0.09—0.11；
延迟一根 bar 后下降到 0.03—0.05。降幅说明大部分表面预测力来自极短周期反转，而非可按
同一收盘价捕获的收益。正文的模型比较、GRU 增量判断和成本层因此统一使用延迟口径；同刻
口径只作为诊断，不作为策略业绩。
