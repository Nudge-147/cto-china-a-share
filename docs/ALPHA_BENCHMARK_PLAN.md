# Alpha 基准方案

第 1 版先交付 raw return 与市场调整收益；Carhart alpha 在第 2 周末补齐。

采用自建 A 股月度四因子，而不是拼接公开因子库。这样因子定义、股票池、滞后处理和可交易性与 CTO 回测共享同一份全 A 数据，面试中可完整说明。

## 因子定义（初版）

- 市场：当月全股票池的流通市值加权收益减无风险利率；无风险利率先以 0 占位，后接入一年期存款/国债月度序列。
- SMB：月初按市值 2 分组、按 BM 3 分组，取小盘组合均值减大盘组合均值。
- HML：同一 2×3 组内，高 BM 组合均值减低 BM 组合均值。
- MOM：按过去 12 至 2 月累计收益 2×3 组，赢家减输家。

## 数据依赖与时点

- 日线：Baostock 单源价格、isST、tradestatus；月底聚合为月收益。
- 月度市值：用 Baostock 不复权日线的 `float_shares = volume / (turn / 100)` 反推流通股本，再乘不复权收盘价；权重使用流通市值。Baostock 季频 balance 接口不提供股本字段，因此不采用“季度股本快照”假设。
- BM：年报账面权益按披露日滞后进入可用集合；不能用报告期末直接前视。
- MOM：月末 t 用 t-12 至 t-2 的累计收益，跳过最近一个月。

第 2 周末将把因子构造、CTO 十分位和 Newey-West alpha 回归接到同一个回测模块。
