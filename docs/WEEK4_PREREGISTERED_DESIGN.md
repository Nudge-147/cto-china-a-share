# 第四周预注册：公告、注意力与 CTO

冻结日期：2026-07-30。本文在查看二维分组结果之前写成；仅当标签分布显示注意力型极端日占比低于 10% 时，才允许重新讨论两个预先指定的阈值（5% 的相对暴涨替代定义、换手率 2 倍阈值），且必须在查看任何二维收益结果前冻结新版本。

## 研究问题

CTO 是否主要刻画无公司特定信息支持、但由注意力和投机驱动的持续性状态？

## 公告事件和窗口

事件数据来自 AkShare 所封装的东方财富公告数据：业绩预告、定期报告、业绩快报，以及分红的预案公告、公告和除权除息日。每个事件在其有效交易日及前后一个交易日形成 `[t-1,t,t+1]` 窗口。原始接口只给日期、不提供发布时间；因此无法识别盘后公告，基准口径把日期映射至当日或下一交易日（非交易日顺延）。这一限制单独报告，不能将缺失的时点静默视为“无新闻”。

“其他重大事项”（融资、并购、质押、诉讼、违规、管理层变动、突发事件）不纳入本轮标签：AkShare 的全市场结构化接口不能可靠地逐项覆盖，不能用公告标题关键词冒充论文 CSMAR 事件库。

## 极端日主定义

1. 用后复权收盘价计算个股日收益；当日全市场横截面中位数为市场收益。
2. 市场调整收益 = 个股日收益 − 当日全市场中位数收益。
3. 对每只股票，以前 250 个交易日的市场调整收益计算 97.5 分位数（当日不进入历史窗口）。市场调整收益严格高于该阈值，才是候选“相对暴涨”。
4. 候选日必须未触及涨停：用不复权的日内最高价与按分四舍五入后的涨停价判定。涨停日保留为单独的稳健性标签，不混入主定义。

预先指定稳健性定义：市场调整收益大于 5%，且未触及涨停。其目的仅是检验结论对时序分位阈值的依赖，不用于挑选更高收益的版本。

## 注意力、信息和基准分类

- 信息型极端日：落入任一公告 `[t-1,t,t+1]` 窗口。
- 注意力型极端日：窗口外，且当日换手率严格高于该股过去 60 个交易日平均换手率的两倍。
- 未分类极端日：窗口外但换手不异常；不强行归入注意力型。

形成月内，股票分类优先级为：有至少一个注意力型极端日则为“注意力型”；否则若有至少一个信息型极端日则为“信息型”；否则为“基准组”。未分类极端日不改变股票分类。

## 冻结的检验和预测

每月在三类股票内分别按 CTO 分为五组，并持有下月。报告 EW 为主、VW 为补充，Newey-West 使用 5 个滞后项。

预先预测：

1. 注意力型 × 低 CTO 的下月收益最低，CTO 五分位收益梯度最陡。
2. 信息型股票中的 CTO 梯度弱于注意力型股票。
3. 注意力型组合的多空衰减曲线更持久，符合“投机磁石状态”而非一次性公告冲击。

标签分布、每月三类股票数和每个二维格子的最小观测数是先验可行性诊断；在该诊断通过前，不查看任何二维组合收益或调整阈值。
