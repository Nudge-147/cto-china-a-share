本节只做八个滚动窗口的描述性对照，不进行回归或因果解释。主指标为延迟一根 bar
入场时，GRU 五种子平均 RankIC 减去固定 LightGBM RankIC；预注册增量门槛为 0.005。

## 结论

1. W2 与 W8 的增量分别只有 0.0030 和 0.0015，低于预先声明的 0.005；将它们列为失效
   窗口不是事后划线。
2. 两个窗口的市场方向相反：W2 上涨 7.55%，W8 下跌 4.40%。它们的平均 20 日波动率也
   不共同处于八窗口中的同一极端。因此，现有八点证据不支持“单一涨跌方向”或“单一高/低
   波动状态”能够解释失效。
3. 两个失效窗口都不与 2023-08-09—2025-03-19 的分钟数据修复 regime 重合；重合度较高
   的 W4—W6 反而全部通过增量门槛。数据修复 regime 因而不是这两次失效的直接解释。
4. 这组对照更适合写成“GRU 增量存在明显时间不稳定性，但八个窗口不足以识别稳定的市场
   状态条件”。不据此做回归、择时规则或 regime-conditioned 模型选择。
