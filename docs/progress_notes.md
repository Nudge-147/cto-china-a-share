## 4. CTO 管道修复与验证（2026-07-22）

- 修复涨跌停判定：先按 `round(prev_close × (1 ± limit_pct), 2)` 计算交易所分价涨/跌停价，再以 0.005 元容差比较；不再直接拿未四舍五入理论值比较。
- 单元测试已通过：包含平安银行 2020-07-06（前收 14.25、涨停价 15.68）以及 2020-08-24 创业板 10%→20% 规则切换。
- 修复年度样本图的尺度问题：股票数量与 eligible rows 使用双 Y 轴，不再把 stocks 线压在 0 附近。
- 小样本诊断中，2022 年后 eligible rows 从约 730 降至约 490，与 603157 退市后剩余 2 只股票一致；这是退市事件被捕捉的验证，不是幸存者偏差。2026 年为年中截断。
- AkShare 全量请求受远端限流/断连影响；Baostock 评估成功，已安装并验证 000001、600519、603157，随后启动全量断点下载。Baostock 后复权和原始价分别保存，避免混源。
- 曾用名重构 ST 方案已退役：Baostock 日线提供逐日 `isST` 与 `tradestatus`，现在直接使用它们进行时点准确的 ST 和停牌过滤；下载器因此重启，旧小样本下载已清理。
- 历史市值管道：Baostock 季频 `query_balance_data` 实测不提供总/流通股本，改用日线 `float_shares = volume / (turn / 100)` 反推流通股本，并以不复权价计算流通市值。三只样本验证中，贵州茅台约 1.63 万亿元、平安银行约 2,131 亿元，量级合理。
- 市值数值加固：`turn < 0.01%`、缺失或停牌时不反推，前向持有最近有效股本；原始反推股本以 20 日滚动中位数平滑，并以 5% 阈值阶梯更新。603157 的原始与阶梯化对比图显示主要跳变被保留、日噪声被压低。
